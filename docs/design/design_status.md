# Metrion Design Status

## Current Status

The logo, branding, colors, typography, and final UI/UX system are not finalized.

## Instructions for Claude Code

- Treat all images in `docs/design/exploratory/` as visual references only.
- Do not treat them as approved final designs.
- Do not hardcode temporary colors, logos, typography, or layouts into core architecture.
- Keep frontend branding configurable and replaceable.
- Do not couple business logic to exploratory UI decisions.
- Final design decisions will be documented separately after approval.
