# CMO 3.0 — M6 Section F traceability (2026-10-31)

Maps each of the 50 section F acceptance tests in `CMO_ACCEPTANCE_TESTS.md` to the automated test that verifies it. Every mapping below was made by reading the test body, not the test name. Status:

- **COVERED** — a test directly verifies the requirement's expected behaviour and its pass/fail assertion.
- **PARTIAL** — related behaviour is tested, but part of the requirement is not (the gap is stated).
- **MISSING** — no test verifies it. (None at the time of writing.)

**Totals: 42 COVERED, 8 PARTIAL, 0 MISSING (50).** "Manually verified" is a separate matter: none of these rows has been checked by hand in a browser except as noted in `CMO_IMPLEMENTATION_MAP.md` section 18.
